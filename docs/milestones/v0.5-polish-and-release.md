# v0.5 — Hotkey palette, App Intents, encrypted backup, auto-update

**Goal:** make Swaplane fast to reach, scriptable from the system, recoverable, and shippable.
**Requirements:** F12 F13 F14 F15. **Prereq:** v0.4 accepted.

## Tasks

### A. Hotkey palette
- [ ] Global hotkey (default ⌃⌥Space, user-configurable; use a maintained approach such as `RegisterEventHotKey` via Carbon API or `NSEvent` global monitor — no Accessibility permission unless unavoidable; document choice).
- [ ] Floating `NSPanel` per UX.md: opens on the screen containing the mouse, all Spaces, over fullscreen apps; fuzzy search over profile label/tool/identity; ↑↓ Enter, ⌘1–9, Esc; shows active + usage; respects Touch ID gate.
- [ ] Palette actions: switch (global), "use in this shell" copy-command (non-secret), open main window, re-import.

### B. App Intents
- [ ] `ProfileEntity` (AppEntity) with queries by label/tool.
- [ ] Intents: `SwitchProfileIntent`, `GetActiveProfileIntent`, `GetUsageIntent` (returns percentages only), `OpenSwaplaneIntent`.
- [ ] Shortcuts/Spotlight surfacing with `AppShortcutsProvider`; gated actions invoke AuthGate; intents never return secrets.

### C. Encrypted backup / restore
- [ ] Export: select profiles → passphrase (≥ 10 chars, strength meter, confirm) → `.swaplanebackup` per SECURITY.md (KDF params in header, AES-GCM). Includes metadata + snapshots + credentials; excludes machine-specific Keychain keys (re-keyed on restore).
- [ ] Import/restore: choose file → passphrase → preview contents → conflict handling (skip / duplicate with new UUID / replace) → re-seal under new local keys.
- [ ] Gated by AuthGate; zeroize passphrase buffers; never log filenames containing identity hints.
- [ ] Round-trip, wrong-passphrase, truncated/tampered file, version-mismatch tests.
- [ ] UI: Backup sidebar section; reminder setting (optional, local).

### D. Auto-update + release engineering
- [ ] Integrate Sparkle 2 (EdDSA keys; public key in Info.plist; private key kept offline/in CI secret store — never in repo).
- [ ] Appcast hosting (static), update channel setting (stable/beta), "Check for updates" UI, automatic check on launch (once per day), release notes.
- [ ] Network allowlist updated for the appcast host only; CI check updated.
- [ ] `scripts/release.sh`: build → sign (Developer ID) → notarize (`notarytool`) → staple → DMG → appcast entry. Document in `docs/RELEASING.md`.
- [ ] Add `SECURITY_CONTACT.md`, `LICENSE` decision, `PRIVACY.md` (states no telemetry, lists the exact network hosts).
- [ ] Crash-safe update: ensure no switch/journal is in flight before relaunch for update; recover journal after.

### E. Final hardening
- [ ] Full security checklist, third-party-style review of Keychain/ACL usage, fuzz IPC/CLI inputs.
- [ ] Accessibility audit (VoiceOver full pass, keyboard-only, contrast).
- [ ] Performance: idle CPU ≈ 0 %, memory < 100 MB, switch timings meet PRODUCT.md targets.
- [ ] Multi-display regression matrix from UX.md.
- [ ] Clean-machine install test (Gatekeeper, onboarding, first import) on a second Mac.
- [ ] Update README with screenshots, install instructions, responsible-use note.

## Acceptance criteria

1. Hotkey opens the palette on the screen where the cursor is, including over a fullscreen app on an external display; switching works fully by keyboard.
2. Shortcuts app can switch profile and read active profile/usage; no secrets exposed in intent results.
3. Backup from Mac A restores to Mac B: all selected profiles usable without re-login (where the vendor's tokens remain valid); wrong passphrase/tamper rejected without side effects.
4. Update flow works end-to-end from a previous build to a new one, signature verified; tampered appcast/binary is rejected.
5. Notarized, stapled DMG installs cleanly on a fresh Mac.
6. Network capture shows only: vendor usage hosts and the appcast host.
7. All earlier acceptance criteria still pass (regression), full manual checklist complete.
