# v0.3 — Codex CLI, then ChatGPT Desktop

**Goal:** extend the adapter model to OpenAI tools. Ship Codex first; ChatGPT desktop only if SPIKE-0 go/no-go allows.
**Requirement:** F10. **Prereq:** v0.2 accepted; SPIKE-0 findings for Codex and ChatGPT.

## Part 1 — Codex CLI

- [ ] `CodexCLIAdapter` per ADAPTERS.md §3: detect credential store mode (file vs keyring), identity from id-token claims (decoded locally, never logged), capture/apply with atomic 0600 writes, verify.
- [ ] Isolation modes: `credentialsOnly` (default) and `fullIsolation` (separate `CODEX_HOME`).
- [ ] Warn if `codex` processes are running.
- [ ] `CodexUsageProvider`: prefer local parsing of latest rate-limit info in session rollouts (no network); optional feature-flagged network source. Fixtures for both.
- [ ] Import wizard + popover section + icon/color defaults for the new tool.
- [ ] Tests: required adapter cases from TESTING.md; token-decode tests with synthetic JWTs; "both stores" edge cases.

## Part 2 — ChatGPT Desktop (conditional)

Gate: SPIKE-0 must show the app's state can be captured/restored (and any Keychain items accessed) without breaking the app or requiring dangerous permissions.

- [ ] If **go**: `ChatGPTDesktopAdapter` using stop → capture → apply → relaunch → verify; identity detection per findings; probe/version gating.
- [ ] If **no-go**: ship a `Tool.chatgptDesktop` entry in an *Unsupported* state with an explanation, hide switching, record reasoning in ARCHITECTURE.md Decisions log. Revisit at next major ChatGPT app update.
- [ ] Usage shown as n/a unless a safe source exists.

## Part 3 — Cross-tool

- [ ] Generalize onboarding to list all detected tools.
- [ ] **Groups** (optional if time): a named set of profiles across tools switchable in one action; sequential transactions with aggregate rollback semantics documented (each tool's transaction independent; report partial success clearly).
- [ ] Update PRODUCT.md, UX.md, SECURITY.md (new storage locations), ADAPTERS.md Verified tables.

## Acceptance criteria

1. Codex: import current login, create a second, switch A↔B 10× — `codex` runs signed in as expected each time without re-login.
2. Codex `auth.json` is never left world/group-readable; backups encrypted; no tokens in logs.
3. Codex usage appears from local data when available; otherwise "n/a" with no errors surfaced as failures.
4. ChatGPT: either working switching with the same acceptance as Claude Desktop, or a clearly documented unsupported state with no regressions to other tools.
5. Adding the new adapters required **no changes** to SwitchEngine/Vault public APIs (validates the abstraction); if changes were needed, document why.
6. All tests, security and accessibility checks pass.
