## Acceptance criteria

1. On a Mac signed into Claude Desktop and Claude Code, the wizard detects both and saves each as a profile.
2. After importing a second account (via empty-profile flow), switching A↔B 10× for each tool leaves each signed in as expected, with no manual re-login.
3. Two profiles created from the **same email** keep independent state (a change in one — e.g., a conversation or setting in Desktop — doesn't appear in the other).
4. Failure injected during apply/relaunch results in automatic rollback with the previous account usable.
5. Killing the app mid-switch → next launch recovers to a consistent state.
6. `find ~/Library/Application\ Support/Swaplane` contains no plaintext credentials; `strings` on snapshots shows no token-like content; Keychain items are non-synchronizable.
7. Logs contain no secrets (test #9 passes).
8. Menu bar item and popover work on built-in and external displays; popover never opens off-screen; works after unplugging the display it was on.
9. Unsupported tool versions disable switching with a clear message.
10. All required tests in TESTING.md pass; manual checklist done; security checklist done.

## Out of scope

Usage display, Touch ID gate, Codex/ChatGPT, shell hooks, hotkey, backup, auto-update.

## Implementation status (updated 2026-11-05, branch `feat/v0.1-claude-core`)

**Built and covered by automated tests (29 passing, `swift test`):**
- SwiftPM package: `SwaplaneCore`, `Vault`, `Adapters`, `SwitchEngine`, `SwaplaneUI`, `SwaplaneApp` (menu bar app), `swaplane-cli` (read-only stub).
- Vault: AES-256-GCM sealed snapshots with per-profile keys in the Keychain, rollback store (keep 3), profile/state persistence, secure removal. Tamper, wrong-key and truncation tests.
- Adapters: Claude Code (`credentialsOnly`) and Claude Desktop (allowlist; path-traversal-safe apply). Constants carry `// VERIFIED: 2026-11-05` notes.
- SwitchEngine: transactional switch (preflight → stop → backup → capture-back → apply → relaunch → verify → commit), automatic rollback, journal + crash recovery, per-tool lock, drift detection, "create empty profile" flow, activity log.
- Tests prove: A↔B round trips (10×), refreshed-token capture-back, failure injection at apply and verify, crash recovery, tampered snapshot aborts untouched, drift abort/discard, same-email profiles stay independent, no plaintext secrets on disk or in logs, 0600/0700 permissions, rollback retention, concurrent switch rejection.
- UI: status item + popover (profiles by tool, switch, progress, Undo toast), main window (Profiles / Activity / Settings), import wizard, rename/recolor/remove, multi-display handling (screen-change observer, window re-homing). `scripts/make-app.sh` builds an ad-hoc-signed `Swaplane.app`.
- Smoke test: the bundled app launches and stays running; CLI `list`/`current`/`version` work.

**Not done / not verified (do before calling v0.1 accepted):**
1. **Manual acceptance on real accounts** (criteria 1, 2, 3, 8): no real switch has been run against live Claude data. Needs a second account and the checklist in TESTING.md. The app has only been launched read-only.
2. **UI not visually verified** (no screen-capture access during development). Check popover layout, dark mode, VoiceOver, and behavior on an external display.
3. **Keychain prompts**: writing to the existing `Claude Code-credentials` item from this ad-hoc-signed build may trigger a macOS access prompt; unverified (SPIKE-0 follow-up 3).
4. **Claude Desktop** relaunch/quit timing and `config.json`/Cookies allowlist sufficiency are tested only against synthetic fixtures; verify with a real second account (SPIKE-0 follow-ups 2 and 4).
5. Drift detection is evaluated when the popover/window opens, **not** via FSEvents.
6. No Xcode project/entitlements yet (SwiftPM + `make-app.sh` only), no CI workflow, no `swift-format` config, no `os.Logger` facade, no host-allowlist script (v0.1 makes no network calls), `fullIsolation` not implemented, "Duplicate" not implemented.
7. Version gating: unverified tool versions are allowed with a warning (only CLI 1.0.83 / Desktop 4.16336.0 are verified); unreadable versions are treated as OK.
