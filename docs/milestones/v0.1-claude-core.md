# v0.1 — Claude core

**Goal:** a usable menu bar app that imports the current Claude Desktop and Claude Code logins and switches between saved profiles safely.
**Prereq:** SPIKE-0 findings for Claude Code + Claude Desktop applied to ADAPTERS.md.
**Requirements:** F1 F2 F3 F4 F5 F6 F7 F16 F17.

## Acceptance criteria

1. On a Mac signed into Claude Desktop and Claude Code, the wizard detects both and saves each as a profile.
2. After importing a second account (via empty-profile flow), switching A↔B 10× for each tool leaves each signed in as expected, with no manual re-login.
3. Two profiles created from the **same email** keep independent state (a change in one — e.g., a conversation or setting in Desktop — doesn't appear in the other).
4. Failure injected during apply/relaunch results in automatic rollback with the previous account usable.
5. Killing the app mid-switch → next launch recovers to a consistent state.
6. `find ~/Library/Application\ Support/Swaplane` contains no plaintext credentials; `strings` on snapshots shows no token-like content; Keychain items are non-synchronizable.
7. Logs contain no secrets (test #9 passes).
8. Menu bar item and popover work on built-in and external displays; popover never opens off-screen; works after unplugging the display it was on.
9. Unsupported tool versions disable switching with a clear message.
10. All required tests in TESTING.md pass; manual checklist done; security checklist done.

## Out of scope

Usage display, Touch ID gate, Codex/ChatGPT, shell hooks, hotkey, backup, auto-update.
